# GymSetu: Your Smart Gym Hub

Create a modern responsive SaaS web app called GymSetu for small and independent gyms in Telangana.

Tagline: Run Your Gym Smarter

For the first version, build only:

Landing page

Login page

Gym Owner Dashboard

Members page

Payments page

Attendance page

Use a modern dark fitness theme with clean cards, tables, charts and mobile-responsive design.

Dashboard should show:

Active Members

Monthly Revenue

Memberships Expiring Soon

Today's Attendance

Pending Payments

Use realistic demo data for a gym in Hyderabad and show all prices in ₹.

Add a left sidebar with:
Dashboard
Members
Payments
Attendance
Settings

Do not build backend integrations yet. Focus only on a polished frontend MVP with reusable components and clean navigation.

Make the design suitable for later integration with Supabase.
